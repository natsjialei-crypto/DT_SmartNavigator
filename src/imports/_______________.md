# 操作导航原型设计描述（三组场景）

## 1. 文档说明

本文档对操作导航应用的三组原型设计思路进行结构化整理，覆盖操作员的预案静默场景、操作员的预案激活场景，以及工艺工程师和班长的预案管理与组态场景。

本文档仅整理原始设计范围，不扩展需求、不新增功能、不修改业务规则。参考截图用于说明设计风格、页面结构和信息呈现方式，最终页面需基于截图进行优化设计。

# 第一组：操作预案静默场景——操作员

## 1.1 场景说明

操作预案未激活时，应用以浮球形式静默显示在 DCS 画面上。操作员可通过浮球打开预案小列表，并按工段查看、选择和处理预案。

## 1.2 默认浮球

- DCS 画面默认显示一个规则形状的原型浮球。
- 浮球位于 DCS 画面的右下角。
- 浮球置于页面顶层显示。
- 浮球的设计风格参考图1和图2。
- 点击浮球后，展开预案小列表。

## 1.3 预案小列表

### 页面结构

- 页面以小列表形式从浮球入口展开。
- 小列表左上角提供工段切换入口。
- 操作员可在“气化装置”和“甲醇装置”之间切换。
- 选择工段后，列表展示该工段下的预案。

## 1.4 预案操作

每一条预案均可点击。点击预案后，提供以下两个操作入口：

| 操作 | 结果 |
|---|---|
| 激活预案 | 直接开启所选预案，进入预案激活场景。 |
| 查看预案 | 打开所选预案的内容进行查看。查看完成后，可关闭内容，也可激活该预案。 |

## 1.5 操作路径

```text
静默浮球
  → 点击浮球
  → 展开预案小列表
  → 选择气化装置或甲醇装置
  → 点击预案
      → 激活预案 → 直接开启预案
      → 查看预案 → 查看内容 → 关闭 / 激活
```

# 第二组：操作预案激活场景——操作员

## 2.1 场景说明

预案激活后，全屏显示预案内容。页面同时呈现预案执行过程、工艺卡片、执行进度、激活计时以及多预案切换信息。

## 2.2 页面整体结构

- 页面采用全屏形式显示。
- 页面参考图3进行优化设计。
- 页面左侧展示预案执行过程记录。
- 页面右侧展示工艺卡片。
- 页面提供预案复位按钮。
- 多条预案同时触发时，通过 Tab 切换不同预案。

### 页面分区

| 区域 | 展示内容 |
|---|---|
| 预案 Tab 区 | 展示同时触发的多条预案，支持切换；每个 Tab 显示该预案的优先级。 |
| 左侧执行区 | 展示预案的执行过程记录。 |
| 右侧工艺卡片区 | 展示6个关键工艺参数实时值和4条历史趋势图。 |
| 进度与计时信息 | 展示预案执行进度百分比和激活后的计时。 |
| 预案操作 | 提供复位按钮，预案执行过程中可随时点击。 |

## 2.3 左侧：预案执行过程记录

- 左侧展示预案的各个执行步骤及其执行过程记录。
- 每个步骤均提供一个小问号入口。
- 点击小问号后，可查看该步骤操作成功的判定条件和 OPC 点位通讯状态。
- 不同步骤的操作成功判定条件数量不同：有的步骤为1条条件，有的步骤为2条条件。
- 执行过程记录的内容形态参考图3。
- 操作成功判定条件的内容形态参考图4。

## 2.4 右侧：工艺卡片

工艺卡片包含两类信息：关键工艺参数实时值和历史趋势。

### 关键工艺参数实时值

- 展示6个关键工艺参数的实时值。

### 历史趋势

- 展示4条历史趋势图。
- 支持切换参数进行显示。
- 每一张趋势图均支持多选参数，并在同一张图中共同查看。
- 趋势图中显示上限横线和下限横线，作为趋势参考。

## 2.5 执行进度与计时

- 展示预案当前执行进度的百分比。
- 展示预案激活后的计时。
- 计时不需要持续跳动显示，只显示一个数字。
- 计时一般采用分钟级即可。

## 2.6 多预案同时触发

- 当多条预案同时触发时，各预案以 Tab 形式展示。
- 操作员可通过 Tab 在不同预案之间切换。
- 每个 Tab 上需显示对应预案的优先级。

## 2.7 预案复位

- 预案激活后提供复位按钮。
- 预案执行过程中可随时点击复位按钮。

# 第三组：操作预案管理场景——工艺工程师

## 3.1 管理预案

### 3.1.1 工程师页面

#### 页面结构

- 页面左侧为工段区域。
- 工段名称支持新增、删除和修改。
- 页面右侧为预案列表。
- 选中左侧某个工段后，右侧显示该工段下的预案。

#### 预案操作

工程师可对每一个预案执行以下操作：

- 编辑
- 查看
- 启用
- 禁用

#### 禁用校验

- 禁用操作需要进行校验。
- 只有 `Disable` 的预案才能禁用。
- 本条按照原始设计描述保留，不修改其状态规则。

### 3.1.2 班长页面

- 班长在另一个与工程师页面类似的页面中进行操作。
- 班长只能看到已启用的预案。
- 班长可对预案执行 `Enable` 和 `Disable` 操作。

## 3.2 组态预案

预案组态包含以下三部分：

1. 配置触发条件。
2. 配置操作规程。
3. 配置工艺卡片。

页面分别参考图5、图6和图7进行优化设计。

## 4. 三组场景关系

```text
操作员：静默场景
  → 通过浮球选择预案
  → 查看预案或激活预案

操作员：激活场景
  → 全屏查看并执行预案
  → 查看执行过程、判定条件、OPC 通讯状态和工艺卡片
  → 查看执行进度、激活计时和多预案优先级
  → 可随时复位预案

工艺工程师 / 班长：管理场景
  → 工程师管理工段和预案
  → 班长对已启用预案执行 Enable / Disable
  → 工艺工程师组态触发条件、操作规程和工艺卡片
```
